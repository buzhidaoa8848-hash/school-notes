1 为什么是 FastAPI

对比FastAPIFlaskDjango
性能⭐ 异步原生 (ASGI)同步 (WSGI)同步 (WSGI)
自动文档⭐ 自动生成 Swagger UI需第三方需第三方
类型检查⭐ Pydantic + 类型提示无无
学习曲线低（10分钟上手）低高（全家桶）
适用场景API 服务、微服务小项目、原型大型单体应用
总结：你要做 AI 应用（抑郁筛查 API），FastAPI 是最佳选择——自动文档方便调试，异步支持高并发，类型安全减少 bug。

3 基础：路由与请求

3.1 HTTP 方法

@app.get("/items")         # GET → 获取资源
@app.post("/items")        # POST → 创建资源
@app.put("/items/{id}")    # PUT → 更新资源
@app.delete("/items/{id}") # DELETE → 删除资源

3.2 路径参数

@app.get("/users/{user_id}")
def get_user(user_id: int):          # 类型自动校验！
    return {"user_id": user_id}

# 访问 /users/42 → {"user_id": 42}
# 访问 /users/abc → 422 错误（类型不对）

3.3 查询参数

@app.get("/search")
def search(q: str = "", limit: int = 10):
    return {"query": q, "limit": limit}

# 访问 /search?q=depression&limit=5

3.4 请求体（用 Pydantic）

from pydantic import BaseModel

class Item(BaseModel):
    name: str
    price: float
    in_stock: bool = True  # 默认值

@app.post("/items")
def create_item(item: Item):
    return {"received": item, "total": item.price * 1.1}
关键理解：FastAPI 会根据类型自动做三件事——
① 校验请求数据（类型不对直接返回 422）
② 生成 API 文档（Swagger UI 上能看到请求格式）
③ 自动补全（IDE 里能提示字段名）

4 Pydantic 模型

Pydantic 是 FastAPI 的核心——用 Python 类型定义数据模型，自动做校验和序列化。

基础模型

from pydantic import BaseModel
from datetime import datetime
from typing import Optional

class Patient(BaseModel):
    id: int
    name: str
    age: int
    phq8_score: Optional[float] = None   # 可选字段
    created_at: datetime = datetime.now() # 默认值

class ScreeningResult(BaseModel):
    patient_id: int
    risk_level: str  # "low" / "medium" / "high"
    confidence: float
    symptoms: list[str]  # 症状列表

嵌套模型

class Session(BaseModel):
    session_id: str
    utterances: list[Utterance]  # Utterance 是另一个模型

class Utterance(BaseModel):
    speaker: str       # "patient" / "therapist"
    text: str
    timestamp: float

校验器

from pydantic import field_validator

class Patient(BaseModel):
    name: str
    age: int

    @field_validator("age")
    @classmethod
    def check_age(cls, v):
        if v < 0 or v > 150:
            raise ValueError("年龄必须在 0-150 之间")
        return v
⚠️ Pydantic v2 的校验器写法变了——用 @field_validator 代替 v1 的 @validator。

5 数据库集成

SQLite + SQLAlchemy（最简单的方案）

# database.py
from sqlalchemy import create_engine
from sqlalchemy.orm import Session, sessionmaker

DATABASE_URL = "sqlite:///./screening.db"
engine = create_engine(DATABASE_URL, connect_args={"check_same_thread": False})
SessionLocal = sessionmaker(bind=engine)
# models.py
from sqlalchemy import Column, Integer, String, Float
from sqlalchemy.orm import DeclarativeBase

class Base(DeclarativeBase):
    pass

class Patient(Base):
    __tablename__ = "patients"
    id = Column(Integer, primary_key=True, index=True)
    name = Column(String)
    phq8_score = Column(Float, nullable=True)
    risk_level = Column(String)

Dependency Injection（FastAPI 精髓）

from fastapi import Depends

def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()

@app.get("/patients/{patient_id}")
def get_patient(patient_id: int, db: Session = Depends(get_db)):
    patient = db.query(Patient).filter(Patient.id == patient_id).first()
    if not patient:
        return {"error": "not found"}
    return patient
Depends 是什么？
FastAPI 的依赖注入系统——你声明参数类型为 Session = Depends(get_db)，FastAPI 自动调用 get_db() 获取数据库连接，请求结束后自动关闭。不用手动管理数据库生命周期。

6 实战：抑郁筛查 API

把大创模型封装成一个完整的 API 服务。

# main.py — 完整示例
from fastapi import FastAPI, Depends, HTTPException
from pydantic import BaseModel
from typing import Optional
import sqlite3, json

app = FastAPI(title="DAIC-WOZ 抑郁筛查服务")

# ── 数据模型 ──
class ScreeningInput(BaseModel):
    text: str                         # 访谈文本
    audio_features: list[float]       # 语音特征（wav2vec2 输出）
    facial_features: Optional[list[float]] = None  # 面部特征

class ScreeningOutput(BaseModel):
    phq8_score: float                 # 预测 PHQ-8 分数
    risk_level: str                   # low / medium / high
    confidence: float                 # 置信度
    key_symptoms: list[str]           # 关键症状

# ── 模拟模型（替换为真实模型） ──
def predict(input: ScreeningInput) -> ScreeningOutput:
    # 这里是你的 MIL 模型推理逻辑
    return ScreeningOutput(
        phq8_score=12.5,
        risk_level="high",
        confidence=0.87,
        key_symptoms=["sleep_disorder", "loss_of_interest"]
    )

# ── API 接口 ──
@app.post("/predict", response_model=ScreeningOutput)
def predict_depression(input: ScreeningInput):
    if len(input.text) < 10:
        raise HTTPException(status_code=400, detail="文本太短，至少10个字符")
    return predict(input)

@app.get("/health")
def health_check():
    return {"status": "ok", "model": "MIL+Attention v1.0"}
💡 扩展思路：
① 换成异步接口，支持并发筛查 async def predict(...)
② 加上数据库记录每次筛查结果
③ 用 BackgroundTasks 异步保存日志
④ 用 FileResponse 返回筛查报告 PDF

7 部署

方案 1：最简单的部署

# 安装生产服务器
pip install uvicorn

# 启动（生产环境）
uvicorn main:app --host 0.0.0.0 --port 8000 --workers 4

方案 2：Docker 部署

# Dockerfile
FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
# 构建并运行
docker build -t screening-api .
docker run -p 8000:8000 screening-api
💡 部署后的访问：
http://你的IP:8000/docs → Swagger UI（可以直接在网页上测试 API）
http://你的IP:8000/predict → 调用筛查接口

8 易错点

#易错点正确做法
1同步代码阻塞事件循环CPU 密集型任务用 BackgroundTasks 或扔到线程池
2SQLite 并发问题SQLite 只支持单写，生产环境换 PostgreSQL
3CORS 未配置前端调用加 from fastapi.middleware.cors import CORSMiddleware
4路径参数类型不对参数用 int 而不是 str，让 FastAPI 自动校验
5开发和生产混用开发用 fastapi dev，生产用 uvicorn
6敏感信息硬编码API key、数据库密码用环境变量 os.getenv()

9 自测题

题1：FastAPI 和 Flask 最大的两个区别是什么？

1. FastAPI 原生支持 async/await（异步），Flask 是同步的
2. FastAPI 自动生成 Swagger 文档，Flask 需要手动配置

题2：以下代码有什么问题？

@app.get("/user/{user_id}")
def get_user(user_id):
    return {"id": user_id}
user_id 没有声明类型，FastAPI 不会自动校验。
正确写法：def get_user(user_id: int):

题3：写一个 POST 接口，接收患者姓名和年龄，返回"患者 X，年龄 Y，登记成功"。

class PatientIn(BaseModel):
    name: str
    age: int

@app.post("/register")
def register(patient: PatientIn):
    return {
        "message": f"患者 {patient.name}，年龄 {patient.age}，登记成功"
    }
