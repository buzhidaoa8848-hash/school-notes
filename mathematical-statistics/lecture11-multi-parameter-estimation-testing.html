1 多参数 MLE

来源：课件第1页

当参数 θ ∈ Ω ⊂ ℝᵖ 是 p 维向量时，MLE 需要解 p 个方程：

似然函数：L(θ) = ∏ f(Xᵢ; θ)
对数似然：l(θ) = ∑ log f(Xᵢ; θ)
MLE 条件：∂L/∂θₖ = 0 或 ∂l/∂θₖ = 0, k = 1, ..., p

例：正态分布 N(μ, σ²)

来源：课件第1-2页

参数 θ = (μ, v)′，v = σ²

l(θ) = −n/2·log 2π − n/2·log v − 1/(2v)·∑(Xᵢ − μ)²

∂l/∂μ = 1/v · ∑(Xᵢ − μ) = 0 → ˆμ = X̄（无偏）
∂l/∂v = −n/(2v) + 1/(2v²)·∑(Xᵢ − μ)² = 0 → ˆv = 1/n·∑(Xᵢ − X̄)²（有偏）

例：一般拉普拉斯分布

来源：课件第2页

f(x) = 1/(2b)·e^−|x−a|/b，参数 θ = (a, b)′

l(a, b) = −n log 2 − n log b − ∑|Xᵢ − a|/b

∂l/∂a = 1/b·∑ sgn(Xᵢ − a) = 0 → â = median{X₁, ..., Xₙ}
∂l/∂b = −n/b + 1/b²·∑|Xᵢ − a| = 0 → b̂ = 1/n·∑|Xᵢ − Q₂|
💡 要点：正态分布 MLE 的 ˆμ = X̄ 无偏，ˆσ² 有偏（分母是 n 而不是 n−1）。拉普拉斯分布的 â 是样本中位数，不是均值。

2 Fisher 信息矩阵

来源：课件第2-3页

在多参数情况下，Fisher 信息量是一个 p × p 矩阵：

定义：I(θ) = Cov{∇ log f(X; θ)}

第 (j, k) 分量：
Iⱼₖ(θ) = Cov(∂/∂θⱼ log f, ∂/∂θₖ log f)

两个等价计算公式：
① Iⱼₖ(θ) = E[(∂/∂θⱼ log f) · (∂/∂θₖ log f)]
② Iⱼₖ(θ) = −E[∂²/∂θⱼ∂θₖ log f(X; θ)]
例：正态分布
θ = (μ, v)′，可算得：
I(θ) = [1/v 0 ]
   [0 1/(2v²)]
I(θ)⁻¹ = [v 0 ]
    [0 2v²]

3 Rao-Cramer 下界 (RCB)

来源：课件第3页

Rao-Cramer 下界：若 Yⱼ = uⱼ(X₁, ..., Xₙ) 是 θⱼ 的无偏估计，则
Var(Yⱼ) ≥ 1/n · [I⁻¹(θ)]ⱼⱼ

其中 [I⁻¹(θ)]ⱼⱼ 是 Fisher 信息矩阵的逆矩阵的第 j 个对角元。
概念定义来源页
有效估计量无偏且方差达到 RCBp3
有效性[I⁻¹(θ)]ⱼⱼ / {n·Var(Yⱼ)}（越接近 1 越好）p3
渐进有效样本量 n → ∞ 时有效性 → 1p4

例：正态分布 ˆμ 和 S²

来源：课件第3-4页

ˆμ = X̄：Var(ˆμ) = v/n = RCB → 有效估计 ✅

S² = nˆv/(n−1)：
(n−1)S²/v ∼ χ²(n−1) → Var(S²) = 2v²/(n−1)
RCB = 2v²/n
Var(S²) > RCB → 不是有效估计
有效性 = (n−1)/n → 渐进有效（n→∞ 时 → 1）

4 MLE 例题详解

正态分布完整流程（考试标准步骤）

Step 1: 写出似然函数
L(μ,σ²) = (2πσ²)^(−n/2) · exp{−∑(Xᵢ−μ)²/(2σ²)}

Step 2: 取对数
l = −n/2·log(2π) − n/2·log(σ²) − ∑(Xᵢ−μ)²/(2σ²)

Step 3: 对 μ 求偏导 → 0
∂l/∂μ = ∑(Xᵢ−μ)/σ² = 0  →  ˆμ = X̄

Step 4: 对 σ² 求偏导 → 0  
∂l/∂σ² = −n/(2σ²) + ∑(Xᵢ−μ)²/(2σ⁴) = 0
→ ˆσ² = ∑(Xᵢ−X̄)²/n

Step 5: 验证 Fisher 信息矩阵
I(θ) = diag(1/σ², 1/(2σ⁴))

Step 6: RCB
Var(ˆμ) = σ²/n = [I⁻¹]₁₁/n  → 有效
Var(S²) = 2σ⁴/(n−1) > 2σ⁴/n = RCB → 渐进有效
⚠️ 考试注意：正态分布 MLE 的 ˆσ² = 1/n·∑(Xᵢ−X̄)² 是有偏的，纠偏后 S² = 1/(n−1)·∑(Xᵢ−X̄)² 无偏但不是有效估计（渐进有效）。

5 多项分布

来源：课件第4-6页

项目内容
试验k 种结果，概率 p₁, ..., pₖ（∑pⱼ = 1）
参数p = (p₁, ..., pₖ₋₁)′（pₖ = 1 − ∑pⱼ 被决定）
单次 p.m.f.f(x;p) = ∏ pᵢˣⁱ · (1−∑pⱼ)^(1−∑xⱼ)
MLEˆpₕ = Tₕ/n，Tₕ = ∑Xₕᵢ ∼ Bin(n, pₕ)
性质无偏 + 方差 = RCB → 有效估计
Fisher 信息矩阵（k−1 维）：
对角元：Iᵢᵢ = 1/pᵢ + 1/pₖ
非对角：Iᵢₕ = 1/pₖ (i ≠ h)

逆矩阵：
[I⁻¹]ᵢᵢ = pᵢ(1−pᵢ)
[I⁻¹]ᵢₕ = −pᵢpₕ (i ≠ h)

6 多参数检验

来源：课件第6-7页

检验 H₀: θ = θ₀ vs H₁: θ ≠ θ₀

方法统计量渐近分布
① 似然比检验 (LRT)χ²_L = −2 log Λ = 2[l(ˆθ) − l(θ₀)]χ²(p)
② Wald 检验χ²_W = (ˆθ−θ₀)′[nI(ˆθ)](ˆθ−θ₀)χ²(p)
③ Score 检验χ²_R = {∇l(θ₀)}′[nI(θ₀)]⁻¹{∇l(θ₀)}χ²(p)

检验 H₀: θ ∈ ω vs H₁: θ ∈ Ω\ω

ω 由 q 个约束定义（0 < q ≤ p）：g₁(θ)=a₁, ..., g_q(θ)=a_q

LRT 统计量：Λ = max_{θ∈ω} L(θ) / max_{θ∈Ω} L(θ) = L(ˆω) / L(ˆΩ)
拒绝域：{Λ ≤ c} 或等价地 {−2 log Λ ≥ χ²_α(q)}

定理 (Hogg 6.5.1)：在正则条件下，H₀ 成立时
−2 log Λ →ᵈ χ²(q)

7 LRT 详解

来源：课件第7-8页

例：正态分布，方差未知，检验 μ = μ₀

问题：X₁,...,Xₙ ∼ N(μ, σ²)，σ² 未知
H₀: μ = μ₀  vs  H₁: μ ≠ μ₀

Step 1: 无约束 MLE (Ω)
ˆμ = X̄,  ˆσ² = 1/n·∑(Xᵢ−X̄)²
L(ˆΩ) = (2πˆσ²)^(−n/2)·e^(−n/2)

Step 2: 约束 MLE (ω: μ = μ₀)
ˆμ₀ = μ₀,  ˆσ₀² = 1/n·∑(Xᵢ−μ₀)²
L(ˆω) = (2πˆσ₀²)^(−n/2)·e^(−n/2)

Step 3: LRT 统计量
Λ = L(ˆω)/L(ˆΩ) = (ˆσ²/ˆσ₀²)^(n/2)

Step 4: 化简
∑(Xᵢ−μ₀)² = ∑(Xᵢ−X̄)² + n(X̄−μ₀)²
→ Λ = [1 / (1 + n(X̄−μ₀)²/∑(Xᵢ−X̄)²)]^(n/2)

Step 5: 等价拒绝域
→ {√n|X̄−μ₀|/√[∑(Xᵢ−X̄)²/(n−1)] ≥ c}
→ {|X̄−μ₀|/(S/√n) ≥ c}  — 这就是 t-检验！
💡 关键理解：LRT 推导出了 t-检验。这说明了 LRT 的"似然比"思路等价于经典检验方法。考试中可能会让你推导类似的等价关系。

8 方差分析 (ANOVA)

来源：课件第8-10页

单因素方差分析

项目内容
假设r 个独立正态总体 N(μᵢ, σ²)，第 i 组有 nᵢ 个样本
H₀μ₁ = μ₂ = ... = μᵣ
无约束 MLEˆμᵢ = X̄ᵢ·，˜σ² = SE/n
约束 MLE (H₀)ˆμ = X̄，˜σ′² = ST/n
LRT 统计量χ²_L = n log(ST/SE) = n log(1 + SA/SE)
精确 F 检验F = [SA/(r−1)] / [SE/(n−r)] ∼ F(r−1, n−r)
近似 LRT{χ²_L ≥ χ²_α(r−1)}
记号说明：
SE = ∑∑(Xᵢⱼ − X̄ᵢ·)²（组内平方和）
SA = ∑nᵢ(X̄ᵢ· − X̄)²（组间平方和）
ST = SE + SA（总平方和）

例：总统选举（多项分布检验）

来源：课件第10页

k=3 位候选人，检验 H₀: p₁ = p₂

LRT 统计量：
χ²_L = 2[T₁ log(2ˆp₁/(ˆp₁+ˆp₂)) + T₂ log(2ˆp₂/(ˆp₁+ˆp₂))]

拒绝域：{χ²_L > χ²_α(1)}

其中 ˆpⱼ = Tⱼ/n，Tⱼ = ∑Xⱼᵢ

9 易错点

#易错点正确理解来源
1多参数 MLE 有偏/无偏混淆ˆμ = X̄ 无偏；ˆσ² = 1/n·∑(Xᵢ−X̄)² 有偏，纠偏后 S² 无偏但不有效p1-2
2Fisher 信息矩阵维度搞错p 个参数 → p×p 矩阵，非对角元素不能忽略p2-3
3RCB 是矩阵的逆的对角元Var(ˆθⱼ) ≥ 1/n·[I⁻¹(θ)]ⱼⱼ，不是 1/(n·Iⱼⱼ)p3
4LRT 统计量自由度H₀: θ=θ₀ 时 df = p（参数个数）；H₀ 有 q 个约束时 df = qp6-7
5混淆三种检验LRT 用似然函数比值；Wald 用 ˆθ 与 θ₀ 的距离；Score 用梯度在 θ₀ 的值p6-7
6多项分布自由度假定错k 种结果 → 参数维度 k−1，不是 k。因为 ∑pⱼ = 1p4-6

10 自测题

题1：正态分布 N(μ, σ²) 的 MLE ˆμ 和 ˆσ² 哪个是有偏的？如何纠偏？纠偏后的估计量是有效估计吗？

ˆμ 无偏。ˆσ² = 1/n·∑(Xᵢ−X̄)² 有偏（分母 n），纠偏后 S² = 1/(n−1)·∑(Xᵢ−X̄)² 无偏。

S² 不是有效估计：Var(S²) = 2σ⁴/(n−1) > RCB = 2σ⁴/n。
有效性 = (n−1)/n → 渐进有效。

题2：有两个参数 θ = (θ₁, θ₂)′。Fisher 信息矩阵 I(θ) 是几乘几的矩阵？RCB 公式中的 [I⁻¹(θ)]₁₁ 是什么？

I(θ) 是 2×2 矩阵。Var(ˆθ₁) ≥ 1/n·[I⁻¹(θ)]₁₁，其中 [I⁻¹(θ)]₁₁ 是逆矩阵的 (1,1) 元素。

注意不是 1/(n·I₁₁) ！因为 I 不是对角矩阵时，逆矩阵的对角元 ≠ 原矩阵对角元的倒数。

题3：LRT 的 −2 log Λ 在 H₀ 下渐近服从什么分布？自由度是多少？

−2 log Λ →ᵈ χ²(q)，其中 q 是 H₀ 下约束条件的个数。
例：H₀: μ=μ₀（1个约束）→ q=1
H₀: μ₁=μ₂=...=μᵣ（r−1个约束）→ q=r−1

题4（推导）：从正态分布 LRT 出发，推导出 t-检验的拒绝域。关键步骤是什么？

关键步骤：展开 ∑(Xᵢ−μ₀)² = ∑(Xᵢ−X̄)² + n(X̄−μ₀)²

得到 Λ = [1 / (1 + n(X̄−μ₀)²/∑(Xᵢ−X̄)²)]^(n/2)
→ {Λ ≤ c} 等价于 {|X̄−μ₀|/(S/√n) ≥ c₂}
这正是 t-检验的拒绝域形式。

题5：多参数检验的三种方法（LRT、Wald、Score）分别在什么时候更方便？

LRT：最通用，但需要同时计算约束和无约束 MLE
Wald：只需要无约束 MLE（ˆθ），适合约束复杂的假设
Score：只需要约束 MLE（θ₀），适合约束下计算简单的假设

三者渐近等价，但小样本下表现不同。
