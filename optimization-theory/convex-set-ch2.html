1 内部·闭包·边界 P3

基本拓扑概念

设 $X \subseteq \mathbb{R}^n$ 是非空集合：

  • 内部点：存在 $r > 0$ 使得 $B(x_0, r) := \{x : \|x - x_0\|_2 \leq r\} \subseteq X$
  • 极限点：存在序列 $\{x_n\} \subseteq X$ 使得 $x_n \to x_0$
概念定义符号
内部所有内部点的集合$\mathrm{int}(X)$
闭包所有极限点的集合$\mathrm{cl}(X)$
边界闭包减去内部$\partial(X) = \mathrm{cl}(X) \setminus \mathrm{int}(X)$

思考：$X = [0,1]$ 中的无理数。$\mathrm{int}(X) = ?$，$\mathrm{cl}(X) = ?$

答案：$\mathrm{int}(X) = \varnothing$（任意两个无理数之间都有有理数），$\mathrm{cl}(X) = [0,1]$（无理数在 [0,1] 中稠密）。

2 开集与闭集 P4

定义

  • $X$ 是开集 $\iff$ $\mathrm{int}(X) = X$
  • $X$ 是闭集 $\iff$ $\mathrm{cl}(X) = X$

性质

#性质
1$\mathrm{int}(X) \subseteq X \subseteq \mathrm{cl}(X)$
2$X$ 是闭集 $\iff$ $X$ 的补集是开集
3任意多个闭集的交集仍是闭集
4有限个闭集的并集仍是闭集

3 凸集定义 P5-6

凸集 (Convex Set)

$\forall x_1, x_2 \in C,\; 0 \leq \theta \leq 1 \implies \theta x_1 + (1-\theta)x_2 \in C$

集合中任意两点之间的线段也包含在该集合中。

思考：若上述性质仅在 $\theta = 1/2$ 成立，该集合是否为凸集？
不一定。例如两个不相交的凸集，其中点可能在中间但线段的其它点不在。

为什么凸集在优化中重要？

算法核心：局部搜索 + 线搜索

  1. 第 $k$ 次迭代得当前点 $x^{(k)}$ 和方向 $d^{(k)}$
  2. $x^{(k+1)} = x^{(k)} + t^{(k)} d^{(k)}$
  3. 重复直到收敛

凸集合保证了线搜索的成立（沿着线段移动不会离开可行域）。

4 经典凸集举例 P8-11

超平面 (Hyperplane)

$\{x \in \mathbb{R}^n : a^\top x = b\}$

$a \neq 0, a \in \mathbb{R}^n, b \in \mathbb{R}$

半空间 (Halfspace)

$\{x \in \mathbb{R}^n : a^\top x \leq b\}$

凸集中最基本的构件。

仿射空间 (Affine Space)

$\{x \in \mathbb{R}^n : Ax = b\}$

$A \in \mathbb{R}^{m \times n}, b \in \mathbb{R}^m$

多面体 (Polyhedra)

$\{x \in \mathbb{R}^n : Ax \leq b\}$

$A \in \mathbb{R}^{m \times n}, b \in \mathbb{R}^m$

欧几里得球 (Euclidean Ball)

$B(x_c, r) = \{x : \|x - x_c\|_2 \leq r\}$

也写为 $\{x_c + r u : \|u\|_2 \leq 1\}$

椭球体 (Ellipsoid)

$E = \{x : (x-x_c)^\top P^{-1}(x-x_c) \leq 1\}$

$P \in \mathbb{S}^n_{++}$，等价于 $\{x_c + A u : \|u\|_2 \leq 1\}$

范数球 (Norm Ball)

$\{x : \|x - x_c\| \leq r\}$

对任意范数 $\|\cdot\|$ 都成立。

范数锥 (Norm Cone)

$\{(x, t) : \|x\| \leq t\}$

欧几里得范数锥 = 二阶锥 (SOC)

正定矩阵锥 (PSD Cone)

对称矩阵集：$\mathbb{S}^n = \{X \in \mathbb{R}^{n \times n} : X = X^\top\}$

半正定矩阵集：$\mathbb{S}^n_+$ — 凸锥

正定矩阵集：$\mathbb{S}^n_{++}$ — 也是凸集

5 凸组合与凸包 P13-16

凸组合 (Convex Combination)

$x = \theta_1 x_1 + \theta_2 x_2 + \cdots + \theta_k x_k$

满足 $\theta_1 + \cdots + \theta_k = 1, \theta_i \geq 0$

凸包 (Convex Hull)

$\mathrm{conv}(S)$ = 集合 $S$ 中所有点的凸组合构成的集合

将非凸可行域凸化可作为松弛方法。

四种组合对比

类型系数条件生成结构
线性组合$\theta_i \in \mathbb{R}$线性子空间 (subspace)
仿射组合$\sum \theta_i = 1$仿射子空间 (affine subspace)
锥组合$\theta_i \geq 0$凸锥 (convex cone)
凸组合$\theta_i \geq 0,\; \sum \theta_i = 1$凸集 (convex set)

包含关系

线性子空间 $\subseteq$ 仿射子空间 $\subseteq$ 凸锥 $\subseteq$ 凸集

反过来：凸锥 $\supseteq$ 凸集也要满足"可缩放"性质。

凸包的性质

  • 凸包总是一个凸集
  • 如果 $X$ 是凸集，则 $\mathrm{conv}(X) = X$
  • $\mathrm{conv}(X)$ 是包含 $X$ 的最小凸集

6 保持凸性的运算 P18-19

设 $C, C_1, C_2 \subseteq \mathbb{R}^n$ 是凸集，$K \subseteq \mathbb{R}^m$ 是凸集，以下集合仍为凸集：

运算定义说明
交集$C_1 \cap C_2$任意多个凸集交集仍凸
Minkowski 和$C_1 + C_2 = \{x+y : x \in C_1, y \in C_2\}$两凸集的元素逐对相加
平移$C + a = \{x + a : x \in C\}$整体移动
缩放$tC = \{tx : x \in C\}$$t \in \mathbb{R}$
笛卡尔积$C_1 \times C_2 = \{(x_1, x_2)\}$乘积空间
坐标投影$\{x_1 : (x_1, x_2) \in C\}$高维映射到低维
线性变换像$AC = \{Ax : x \in C\}$任意线性映射
线性变换原像$A^{-1}K = \{x : Ax \in K\}$逆映射

记忆口诀

凸集经过交和、平移、缩放、投影、线性变换——全部保持凸性。这是构造复杂凸集的基本工具。

7 分离超平面定理 P21

分离超平面定理 (Separating Hyperplane Theorem)

如果 $C$ 和 $D$ 是非空不相交的凸集，则存在 $a \neq 0, b$ 使得：

$$a^\top x \leq b \quad \forall x \in C, \qquad a^\top x \geq b \quad \forall x \in D$$

超平面 $\{x \mid a^\top x = b\}$ 将 $C$ 和 $D$ 分离。

几何含义

两个凸集如果不相交，一定有"一刀切"把它们分开。这是凸分析中最基本的定理之一，也是对偶理论的几何基础。

8 支撑超平面定理 P22

支撑超平面 (Supporting Hyperplane)

对于集合 $C$ 在边界点 $x_0$ 的支撑超平面为：

$$\{x \mid a^\top x = a^\top x_0\}$$

其中 $a \neq 0$，且 $a^\top x \leq a^\top x_0$ 对所有 $x \in C$ 成立。

支撑超平面定理

如果 $C$ 是凸集，则在 $C$ 的每一个边界点都存在一个支撑超平面。

⚠ 注意：支撑超平面定理是分离超平面定理的推论——将边界点视为一个单点集 $\{x_0\}$，若 $x_0 \notin \mathrm{int}(C)$ 则 $\{x_0\}$ 与 $C$ 可分离。

自测题

Q1：多面体 $\{x \mid Ax \leq b\}$ 一定是凸集吗？

是。多面体是有限个半空间 $\{x \mid a_i^\top x \leq b_i\}$ 的交集。每个半空间是凸集，交集保持凸性。

Q2：两个凸集 $C_1, C_2$ 的并集一定是凸集吗？

不一定。例如两个不相交的圆盘的并集不是凸集（两点连线经过空隙区）。只有交、和、线性变换保持凸性，并集一般不保持。

Q3：如果 $X$ 是凸集，$\mathrm{conv}(X)$ 和 $X$ 有什么关系？

$\mathrm{conv}(X) = X$。因为凸包的极小性：$\mathrm{conv}(X)$ 是包含 $X$ 的最小凸集，而 $X$ 本身就是凸集，所以相等。

Q4：两个不相交的凸集是否一定可以被超平面严格分离？

不一定。分离超平面定理给出的是"弱分离"（$a^\top x \leq b \leq a^\top y$），允许在超平面上重合。严格分离需要更强的条件（如两个凸集闭且一个有界）。
