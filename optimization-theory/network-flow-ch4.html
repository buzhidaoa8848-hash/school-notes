1 基本概念

来源：课件第6-7页

有向图

G = (V, E)
- V = 顶点集（vertices）
- E ⊆ V × V = 有向边集（directed edges）
- (i, j) 表示从顶点 i 到 j 的有向边

网络流

G = (V, E, s, t, U)
- s = 源点 (source)
- t = 汇点 (sink)
- 容量：每条边 (i,j) 有容量 uij ≥ 0
- 表示一个从源点到汇点的"运输网络"

s-t 流 (Flow)

来源：课件第9页

每条边上的流量 xij ≥ 0 需满足：

① 容量约束：0 ≤ xij ≤ uij，∀(i,j)∈E

② 流量守恒：∑xij = ∑xki，∀i∈V\{s,t}
即：除源点汇点外，流入量 = 流出量
💡 直觉理解：就像水管网络——每根水管有最大容量，中间节点不存水，水从源头流到终点。

2 最大流问题

来源：课件第10-11页

问题定义

目标：从源 s 到汇 t 的总流量最大化

总流量：val(x) = ∑xsj − ∑xis（源点净流出）

约束：
 ① 容量约束：0 ≤ xij ≤ uij
 ② 流量守恒：∑xij = ∑xki，∀i∈V\{s,t}

算法比较

算法复杂度特点
Ford-FulkersonO(m · |fmax|)基础增广路思想，复杂度依赖最大流值
Edmonds-KarpO(nm²)BFS 找最短增广路，多项式时间
DinicO(n²m)分层图 + 阻塞流，竞赛中最常用
Orlin (2013)O(nm)理论最优界
考试/面试重点：Dinic 算法
- 步骤1：BFS 建分层图（level graph）
- 步骤2：DFS 找阻塞流（blocking flow）
- 重复直到源点到不了汇点

3 最小割问题

来源：课件第13-16页

s-t 割的定义

割 (Vs, Vt) 是顶点集 V 的一个划分：
- Vs ∩ Vt = ∅, Vs ∪ Vt = V
- s ∈ Vs, t ∈ Vt

割的容量 = 从 Vs 到 Vt 的所有边的容量之和
= ∑{uij : i∈Vs, j∈Vt}
最小割问题：找到容量最小的 s-t 割
整数规划模型：
min ∑uij · yij
s.t. yij = max{zi − zj, 0}
  zs = 1, zt = 0
  zi ∈ {0, 1}
💡 理解：割就是"切断"一些边让 s 到不了 t。最小割就是切最少的容量让网络断开。这在图像分割、网络可靠性分析中都有应用。

4 最大流-最小割定理

来源：课件第15-19页

核心定理

最大流的值 = 最小割的容量

即：max{val(f)} = min{cap(Vs, Vt)}
证明思路：
1. 对于任意可行流 f 和任意割 (Vs, Vt)：
 val(f) = f(Vs, Vt) − f(Vt, Vs) ≤ cap(Vs, Vt)
2. 当算法终止（无增广路），找到的割恰好达到等号
对偶关系原始问题对偶问题
最大流最小割
目标最大化最小化
变量流 xij割标记 zi, yij
最优值相等相等
💡 意义：这是线性规划强对偶定理的一个特例。网络流问题的整数解性质（TUM）保证了最优解是整数。

5 算法详解

5.1 Ford-Fulkerson 增广路

Algorithm Ford-Fulkerson:
  f = 0
  while 存在增广路 P from s to t:
    δ = min residual capacity on P
    沿 P 增加流 δ
  return f

5.2 Edmonds-Karp（BFS）

与 FF 相同，但找增广路时：
  - 用 BFS 找最短路径（边数最少）
  - 保证 O(nm²) 时间
  - 避免 FF 的低效（如容量为无理数时的无限循环）

5.3 Dinic（竞赛之王）

Algorithm Dinic:
  f = 0
  while BFS from s to t 可建立分层图:
    在分层图上 DFS 找阻塞流
    累加 f
  return f
  
核心优化：
  - 当前弧优化（cur[i]）：记录每个点已经搜到哪条边
  - 多路增广：一次 DFS 找到多条增广路
考试重点：Dinic 手算步骤
1. BFS 从 s 到 t，给每个点标层数（level）
2. 在分层图上 DFS 找增广路到 t
3. 计算路径上的最小剩余容量
4. 更新流量
5. 重复直到 BFS 到不了 t

6 最小费用流

来源：课件第24-30页

6.1 运输问题（Transportation）

设定：供应点 i（供应量 si）→ 需求点 j（需求量 dj）
成本：每单位运输成本 cij

模型：
min ∑cijxij
s.t. ∑xij = si, ∀i
  ∑xij = dj, ∀j
  xij ≥ 0

6.2 最小费用流

G = (V, E, U, C, D)
- uij: 容量
- cij: 单位流量成本
- di: 节点 i 的净需求（供应为正，需求为负）

模型：
min ∑cijxij
s.t. ∑xki − ∑xij = di, ∀i（流量守恒 + 供需）
  0 ≤ xij ≤ uij

6.3 最小费用最大流

先跑最大流找 f*，再在流量 = f* 的约束下最小化费用。

算法：Successive Shortest Augmenting Path
- 在残量网络上用 Bellman-Ford / Dijkstra（有势）
- 每次找 s→t 最短（最便宜）的增广路
- 增广直到最大流量

7 全单位模性（TUM）

来源：课件第32-38页

为什么网络流的整数解自动成立？

全单位模矩阵 (TUM)：所有方子矩阵的行列式 ∈ {−1, 0, 1}

定理：如果约束矩阵 A 是 TUM，b 是整数向量，则 {Ax = b, x ≥ 0} 的所有顶点解都是整数解。

节点-边关联矩阵

对于有向图 G = (V, E)，节点-边关联矩阵 A ∈ ℝn×m：
Aij = −1（边 j 离开顶点 i）
Aij = 1（边 j 进入顶点 i）
Aij = 0（其他）

A 是 TUM ← 这就是为什么网络流的 LP 解自动是整数！
推论：
- 最大流、最小割、最小费用流、运输问题
- 所有这些都是 LP，但因为 TUM，解自动整数
- 不需要用整数规划求解器，用 LP 就够
- 考试中可以说"由于约束矩阵是全单位模的，解自动为整数"

8 应用：AGV 调度案例

来源：课件第40-52页

问题描述

AGV（自动导引车）调度优化
- 有多个 AGV（车辆）、充电站（stations）、工位（workstations）
- 目标：安排 AGV 到充电站、充电站到工位
- 约束：每个 AGV 去一个站、每站一个 AGV、每站一个工位、工位容量

模型

决策变量：
  x_ij ∈ {0,1}: AGV i → 充电站 j
  y_jk ∈ {0,1}: 充电站 j → 工位 k

约束：
  ∑x_ij ≤ 1 ∀i         (每个 AGV 最多一个站)
  ∑x_ij ≤ 1 ∀j         (每个站最多一个 AGV)
  ∑y_jk ≤ 1 ∀j         (每个站最多一个工位)
  ∑y_jk ≤ 3 ∀k         (每个工位最多 3 个站)
  ∑x_ij = ∑y_jk ∀j     (站的一致性：有 AGV 才有工位)

最大流版本：最大化 AGV 使用数
max ∑∑ x_ij

最小费用版：最小化总行驶距离
min ∑ c1_ij·x_ij + ∑ c2_jk·y_jk
💡 和你的大创的联系：AGV 调度 = 二分图匹配 + 资源分配。你的 MIL attention 也在做"资源分配"——把 attention 权重分配给最重要的 utterance。抽象的数学模型可以跨越完全不同的应用领域。

9 易错点

#易错点正确理解来源
1流量守恒忘了 s 和 t守恒条件对 中间节点 成立，s 和 t 不守恒（s 净流出，t 净流入）p9
2割的容量 = 所有跨割边之和只算 Vs→Vt 的边，不算 Vt→Vs 的（反向边不算）p13
3Ford-Fulkerson 复杂度误解O(m·|f|)，如果最大流值很大或容量无理数，可能极慢。Edmonds-Karp 用 BFS 解决p11
4TUM 适用范围节点-边关联矩阵是 TUM，但加了额外约束后可能就不是了p35-38
5残量网络忘记反向边每次增广后，要加反向边（容量 = 已用的流量）。Dinic 算法中"反向边退流"是核心机制标准
6最小费用流的势函数Dijkstra 在有负边权的图中不能用，但用势函数 (potential) 可以转换为非负权p27

10 自测题

题1（基础）

一个网络流有 5 个节点、8 条边。Dinic 算法的一轮迭代中，BFS 做了什么？

BFS 从源点 s 出发，计算每个点到 s 的最短距离（按边数），建立分层图。
如果 BFS 到达不了 t，算法终止。
如果到了 t，下一阶段只在分层图上用 DFS 找增广路。

题2（定理理解）

解释"最大流 = 最小割"定理为什么成立？这个定理直接推了什么？

对偶性。最大流是"最大化从 s 到 t 的流量"，最小割是"最小化切断 s 到 t 所需容量"。
线性规划强对偶定理保证两者相等。

直接推论：
① 最大流算法的终止条件（无增广路）同时证明了最小割
② 可以在 O(n²m) 时间内同时算最大流和最小割

题3（应用）

运输问题为什么不需要整数约束，解自动是整数？

约束矩阵是节点-边关联矩阵（每列两个非零元：1 和 -1），这是全单位模矩阵（TUM）。
TUM 的性质：任何方子矩阵的行列式 ∈ {−1,0,1}。
当约束矩阵是 TUM、右侧 b 是整数时，LP 的顶点解自动是整数。
所以运输问题不需要声明 x_ij ∈ {0,1}，x_ij ≥ 0 就够了。

题4（计算）

一个网络有 3 条从 s 到 t 的路径。路径 A 容量 5，B 容量 3，C 容量 2。所有路径共享一段容量为 6 的公共边。最大流是多少？

由于公共边容量为 6，三条路径总需求 5+3+2=10，但公共边只能过 6。
最大流 = 6。
最小割 = 公共边的容量 6（或从源点到三个路径起点的某个组合，但最少是 6）。
最大流 = 最小割 = 6 ✅
