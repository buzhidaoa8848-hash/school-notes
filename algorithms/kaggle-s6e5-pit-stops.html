4 Baseline 思路

Day 1：最简 Baseline（15分钟出分）

from lightgbm import LGBMRegressor
from sklearn.model_selection import KFold
from sklearn.metrics import mean_squared_error

# 简单预处理
train = pd.read_csv("train.csv")
test = pd.read_csv("test.csv")

# 分离特征和目标
X = train.drop(columns=["id", "pit_stop_duration"])
y = train["pit_stop_duration"]
X_test = test.drop(columns=["id"])

# 处理类别特征
for col in X.select_dtypes(include=["object"]).columns:
    X[col] = X[col].astype("category")
    X_test[col] = X_test[col].astype("category")

# 训练 LightGBM
model = LGBMRegressor(
    n_estimators=1000,
    learning_rate=0.05,
    max_depth=7,
    verbosity=-1
)
model.fit(X, y, eval_set=[(X, y)], eval_metric="rmse")

# 预测
preds = model.predict(X_test)

# 提交
sub = pd.DataFrame({"id": test["id"], "pit_stop_duration": preds})
sub.to_csv("submission.csv", index=False)

5 模型选择

模型适合原因优点缺点
LightGBM 表格数据的王者 快、省内存、原生支持类别特征 小数据易过拟合
CatBoost 类别特征多的竞赛首选 原生处理类别变量、ordered boosting 比 LightGBM 慢一点
XGBoost 稳定可靠 正则化强、不易过拟合 类别特征需要编码
Stacking Ensemble 冲榜用 融合多个模型的优势 训练时间长、易过拟合
推荐路线：Day1 LightGBM baseline → Day2 CatBoost 对比 → Day3 调参 + 融合

8 易错点

#易错点正确做法
1类别特征未处理直接喂模型LightGBM 用 .astype("category")，CatBoost 原生支持
2用 train_test_split 代替 CVPlayground 用 5-fold CV 更稳
3不过早停，模型过拟合LightGBM 设 early_stopping(100)
4提交格式不对确保列名和 sample_submission.csv 完全一致
5忘记 shulffleKFold 要设 shuffle=True
6训练集和测试集处理不一致特征工程步骤必须完全相同地应用于 test
Playground 特别提醒：合成数据通常没有明显的时间顺序或分组结构，不需要 StratifiedKFold 或 GroupKFold。直接用普通 KFold 即可。

自测题

题1：Playground S6E5 的评价指标是什么？应该怎么理解这个指标？

RMSE（均方根误差）。数值越小代表预测越准。RMSE 对大误差惩罚较大（因为误差平方），意味着如果你有少数预测偏差很大的样本，RMSE 会很难看。

题2：类别特征很多，你应该选哪个模型？为什么？

CatBoost 或 LightGBM。CatBoost 原生处理类别特征（不需要 .astype("category")），LightGBM 需要转换但速度更快。建议两个都试。

题3：5-fold CV 的预测结果怎么整合成最终提交？

5 个模型分别对 test 集做预测，取平均值：test_preds = np.mean([m.predict(X_test) for m in models], axis=0)。平均能降低单模型的方差。
