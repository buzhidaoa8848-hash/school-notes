2 CatBoost 是什么

核心特色

特性说明为什么重要
Ordered Boosting每个样本只用前面的样本训练，类似在线学习减少 Target Leakage，比传统 Boosting 更抗过拟合
原生类别特征直接传字符串列，不需要 One-Hot / Label Encoding省事 + 不丢失信息（避免高基数特征维度爆炸）
Symmetric Trees对称二叉树，每层用相同分裂条件预测极快、不容易过拟合、可解释性略好
Ordered TS类别特征的目标编码用在线方式计算比传统 Target Encoding 更少过拟合

三句话理解 CatBoost

一句话
和 XGBoost/LightGBM 一样是梯度提升树，但把类别特征的处理直接做进了算法里。
第二句话
训练时不把所有数据一次性用于计算梯度，而是类似"在线学习"逐样本更新——这就是 Ordered Boosting。
第三句话
树的形状是"对称的"（每层分裂用同样的条件），牺牲了一点灵活性换来了更稳的泛化。
一句话总结
类别特征多、数据不太大、怕过拟合 → 用 CatBoost

3 CatBoost vs XGBoost vs LightGBM

对比维度CatBoostXGBoostLightGBM
类别特征✅ 原生支持❌ 需编码⚠️ 需 .astype("category")
训练速度较慢（尤其大数据）中等🚀 最快
默认参数效果⭐ 最好（不用调参就挺强）中等需调参
过拟合控制⭐⭐ 最强（Ordered Boosting）较强（正则化项多）一般（叶子数多易过拟合）
小数据表现⭐⭐ 最优中等较差（容易过拟合）
GPU 支持✅✅✅
预测速度🚀 最快（对称树）快快
💡 选型建议
Porto Seguro 这种保险数据：类别特征多 + 数据约 60 万行 → CatBoost 是很自然的首选
如果你特征工程做得深、特征变成纯数值 → LightGBM 更快
通常的建议是：CatBoost 打 baseline → LightGBM 冲榜

4 Porto Seguro 数据特点

特点说明对建模的影响
严重不平衡96.4% 未理赔 : 3.6% 理赔不能用准确率评估，需用 Gini / AUC
匿名特征特征名 ps_ind_xx, ps_reg_xx, ps_car_xx 等无法做业务层面的特征解释，纯数据驱动
混合类型binary 特征（0/1）+ 连续特征CatBoost 自动识别 binary 为类别型
缺失值部分特征有缺失（以 -1 标记）CatBoost 原生处理缺失值，不需要填充
Gini 指标Normalized Gini Coefficient和 AUC 等价：Gini = 2×AUC − 1

特征命名规则

ps_ind_xx    → 个体特征（年龄、性别、驾驶经验等）
ps_reg_xx    → 区域特征（地区相关）
ps_car_xx    → 车辆特征（车型、车龄、马力等）
ps_calc_xx   → 计算特征（保险公司计算出的分数，通常可删除）
⚠️ 关键陷阱：ps_calc_xx 系列特征通常是保险公司算出来的"分数"，在训练集和测试集中是固定的随机数——对预测没有帮助，Kaggle 社区一般直接删除。

5 Notebook 逐行拆解

来源：kailex/catboost-baseline-0-676

完整代码（约 40 行）

# ── 1. 导入 ──
import pandas as pd
import numpy as np
from catboost import CatBoostClassifier, Pool

# ── 2. 加载数据 ──
train = pd.read_csv("../input/train.csv")
test = pd.read_csv("../input/test.csv")

# ── 3. 分离 X 和 y ──
X = train.drop(["id", "target"], axis=1)
y = train["target"]
X_test = test.drop(["id"], axis=1)

# ── 4. 识别类别特征 ──
cat_features = list(X.select_dtypes(include=["object"]).columns)
# 也把 binary 特征标记为类别
for col in X.columns:
    if X[col].nunique() == 2:
        cat_features.append(col)
cat_features = list(set(cat_features))

# ── 5. 创建 Pool 对象 ──
train_pool = Pool(X, y, cat_features=cat_features)
test_pool = Pool(X_test, cat_features=cat_features)

# ── 6. 训练 ──
model = CatBoostClassifier(
    iterations=1000,
    learning_rate=0.03,
    depth=6,
    eval_metric="AUC",
    random_seed=42,
    verbose=200,
    early_stopping_rounds=100
)
model.fit(train_pool, eval_set=train_pool)

# ── 7. 预测 ──
preds = model.predict_proba(X_test)[:, 1]

# ── 8. 提交 ──
sub = pd.DataFrame({"id": test["id"], "target": preds})
sub.to_csv("submission.csv", index=False)

逐行解释

代码段在做什么为什么这么做
cat_features = list(X.select_dtypes(include=["object"]).columns) 找出所有字符串类型的列 CatBoost 需要知道哪些是类别特征，才能自动做 Ordered TS 编码
Pool(X, y, cat_features=cat_features) 创建 CatBoost 内部数据结构 Pool 比直接传 DataFrame 更快，且自动处理特征类型
eval_metric="AUC" 用 AUC 作为评估指标 Porto Seguro 的评价指标是 Gini，AUC 和 Gini 等价（Gini = 2×AUC − 1），所以优化 AUC 就是优化 Gini
early_stopping_rounds=100 验证集 100 轮不提升就停止 防止过拟合，自动找到最佳迭代次数
eval_set=train_pool 用训练集自己做验证 ⚠️ 这个 notebook 直接用训练集做 eval_set，没有做 train/val split——这是偷懒做法，正经做应该分出一部分做验证
⚠️ 这个 notebook 的一个问题：直接用训练集做 eval_set（没有分验证集），early_stopping 的效果会打折扣。更好的做法是手动 split 出一部分数据做 eval_set，或者用 CV。

6 特征工程要点

# Porto Seguro 经典特征工程（来自高分 notebook）

# 1. 删除无用特征
drop_cols = [col for col in train.columns if 'ps_calc_' in col]
X = X.drop(columns=drop_cols)

# 2. 组合特征（交互特征）
X["ind_reg"] = X["ps_ind_01"] * X["ps_reg_01"]  # 个体×区域交互
X["car_reg"] = X["ps_car_01"] * X["ps_reg_01"]   # 车辆×区域交互

# 3. 统计特征
# 按车辆类型分组统计理赔率
car_target_mean = train.groupby("ps_car_01_cat")["target"].mean()
X["car_target_mean"] = X["ps_car_01_cat"].map(car_target_mean)

# 4. 缺失值标记
for col in X.columns:
    if X[col].isnull().any():
        X[col + "_na"] = X[col].isnull().astype(int)

# 5. 数值分箱
X["ps_reg_01_binned"] = pd.qcut(X["ps_reg_01"], q=10, labels=False, duplicates="drop")

8 易错点

#易错点正确做法
1没有指定 cat_featuresCatBoost 虽然自动识别，但显式指定更可靠：model.fit(X, y, cat_features=cat_features)
2用 Pool 时不传 cat_featuresPool(X, y, cat_features=cat_features) — 三者都要传
3分类问题用 predict() 而不是 predict_proba()提交需要的是概率，不是类别标签：predict_proba(X)[:, 1]
4忘记处理不平衡CatBoost 可加 auto_class_weights="SqrtBalanced"
5用 accuracy 评估96% 负样本，全预测 0 也有 96% 准确率。必须用 AUC / Gini
6eval_set 直接用全部训练集如上所述，应该手动 split 出验证集

9 自测题

题1：CatBoost 和 LightGBM 最大的区别是什么？

CatBoost 用 Ordered Boosting（在线学习方式更新梯度），LightGBM 用 GOSS + EFB。CatBoost 原生处理类别特征（不需要编码），LightGBM 需要 .astype("category")。CatBoost 树是对称的，LightGBM 是叶子节点生长。

简单记：CatBoost = 类别特征友好 + 抗过拟合；LightGBM = 数据量大时更快

题2：Porto Seguro 的评价指标是 Gini，为什么 notebook 里设置 eval_metric="AUC"？

因为 Normalized Gini = 2 × AUC − 1。优化 AUC 等价于优化 Gini，而 CatBoost 原生支持 AUC 作为 eval_metric，计算更方便。

题3：为什么 Porto Seguro 不能用准确率（accuracy）评估模型？

因为严重不平衡：96.4% 是负样本（未理赔），3.6% 是正样本。如果你全部预测为 0，准确率是 96.4%——看起来很高，但模型其实什么都没学到。

需要评估的是模型区分两个类别的能力（AUC/Gini），而不是预测的"准不准"。
